# 待补充材料

以下清单独立于演示正文。正文只在必要位置显示“待补充 / 待测 / 待确认”。

## 1. 最优先：首发客户和评价基线

- 目标设备、客户类型、实际使用环境、需求访谈或需求书。
- 当前可选方案的具体型号、算法、光学/机械结构及工作流程。
- 当前主要瓶颈究竟在传感器读出、焦点估计、控制计算还是执行器。
- 同一任务质量门槛：焦点/离焦量误差、成像质量、失败条件与测试输入范围。
- 分别定义并测量：焦点估计时间、控制指令生成时间、完整对焦完成时间；说明迭代次数与统计口径。
- 客户愿意试用的条件、接口、模型更新方式、导入成本和验收流程。没有客户承诺时，不写成已有合作。

## 2. 原型、实验与论文证据

- 蓝色 PCB 与视频中绿色板卡的版本关系、BOM、接线图、模型拓扑及权重配置。
- 小车实验是否完全板上推理、外部设备参与情况、数据集与任务定义。
- 板级端到端时延、计算段时延、全系统功耗或单次任务能耗的原始测量记录与仪器信息。
- 重复运行次数、成功率/误差分布、失败案例、环境变化；不能从视频反推速度、功耗或鲁棒性数字。
- `error-params.pdf` 对应代码和原始数据：图例与模型参数量、权重扰动分布、独立/相关扰动、随机种子、运行次数、阴影定义。
- **需要作者复核的不一致**：图b中部分较大模型在高扰动区下降更快，但申请书第18页文字概括为大模型更稳定。本稿保留图、明确限制，没有作出“越大越耐误差”的结论。
- 增大规模的面积、功耗、互连和外围开销；物理器件噪声、温度、老化和极端输入测试。
- KANalogue正式稿/预印本链接、版本日期与当前投稿状态；既有组会只支持“Rebuttal”，不支持“已录用”。
- node efficiency的原文定义、分母是物理节点还是参数、同任务质量的比较基线，以及外围/转换电路是否计入。未核实前不放倍率。

## 3. 工程与知识产权

- 器件与CMOS工艺兼容性、PDK、模拟与混合信号仿真、PVT结果。
- 40 nm是否确有选型依据；当前材料不足，所以正文未写具体节点。
- 验证芯片、SiP/模块的工程顺序、互连、供电、封装测试与调试方案。
- ADC/DAC、控制、存储、接口的系统预算；不要仅拿模拟核心对比完整数字系统。
- 核心成员履历、分工、投入方式与需补齐的工程岗位。
- 专利受理/授权文件、当前法律状态、申请人/权利人、转让或许可安排；申请书中的5个申请号不等于5项授权或公司自有资产。
- 团队与项目对外名称及现有研究材料可披露范围。

## 4. 融资与里程碑

- 本轮融资金额及资金用途比例；科研经费与股权融资分别说明。
- 阶段周期、人员计划、流片/封装/测试及光机平台报价。
- 每个交付物的数值验收门槛、测试协议、继续/停止决策条件与替代方案。
- 首轮客户试用形式、反馈与迭代安排；不要预填未确认订单、客户或收入。
